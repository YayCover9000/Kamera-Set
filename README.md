# Kamera-Set

Planung für Kamera-Zubehör: Was suchen, was passt zusammen, was lohnt sich zu verkaufen.

| Datei | Zweck |
|---|---|
| [SUCHLISTE.md](SUCHLISTE.md) | Zubehör, nach dem ich suche (mit Priorität, Preisrahmen, Kompatibilitäts-Anforderungen) |
| [INVENTAR.md](INVENTAR.md) | Meine aktuellen Kameras und Objektive (Mount, Sensorformat, Zustand) |
| [KOMPATIBILITAET.md](KOMPATIBILITAET.md) | Matrix: Was passt an was (Bajonett, Adapter, Einschränkungen) |
| [VERKAUF.md](VERKAUF.md) | Kandidaten zum Verkauf mit Preisschätzung |
| `fotos/` | Fotos von Kameras/Objektiven zur Identifikation |

## Ablauf
1. Suchliste füllen (grob reicht, wird später präzisiert).
2. Fotos/Infos zu vorhandener Ausrüstung in `fotos/` bzw. `INVENTAR.md` ablegen.
3. Kompatibilität prüfen und Matrix pflegen.
4. Preise vergleichen (Neu/Gebraucht) und Verkaufskandidaten markieren.
